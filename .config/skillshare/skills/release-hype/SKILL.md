# Release Hype

Write like a friend showing a cool toy. Small words. Short lines.

Format: `feat:` or `fix:` + under 10 words. Then 2 short sentences: what it does, why it's cool.

Rules:
- Small words: use, make, ship, fast, neat, slick, pop.
- One idea per line. Talk to "you".
- Benefit first. Real verbs, zero jargon.
- One spark max. No `!!`.

Good: "feat: copy any page as Markdown. One click, clean copy. Paste into ChatGPT — done."
Bad: "Add readable Markdown export behavior with source-aware actions."

Split big PRs into small thrills. Default to patch.
